# Mount the CrisisFusion map plugin as the desk's incident map

* Type: implementation
* Scope: `crisisfusion_map/`, `dualuse/mapview.py`, `dualuse/api.py`,
  `dualuse/ui.py`, `tests/test_mapview.py`, `tests/test_map_*.py`,
  `pyproject.toml`, `.claude/launch.json`
* Related: [2026-10-17-005-track-and-idea.md](2026-10-17-005-track-and-idea.md)

## Context

* A classmate's separate demo, CrisisFusion plugins v1.0.0, has three plugins:
  scoring, map and OpenAI Realtime voice. We compared them with our desk
  on Sat 2026-10-17 PT.
* Our desk already has evidence-quoted tiers, sticky IMMEDIATE, a queue and a
  web phone, but no map. The `la-211` profile serves Los Angeles, which is
  the plugin's map scope.

## Decision

* Vendor only the map plugin and mount it at `/plugins/map/`. The UI gets an
  "Incident map" workspace that embeds the plugin page in an iframe.
* `MapSync` copies queue calls into an in-memory map store from a 1 s
  background thread, so injected surge calls appear too. A new revision is
  sent only when the content changes. Sync errors show in `/state` and in
  the UI. A desk reset replaces the map, because call ids restart.
* The plugin is enabled at startup. NWS/USGS refresh, Census geocoding,
  OSM tiles and device location still need their own clicks.
* Dual-use: on an ordinary day the map shows where callers say they are.
  In a crisis, the same build shows live NWS alerts (a Red Flag Warning was
  active for LA during the test) next to those calls. Map color never changes
  a tier.
* Not adopted: the scoring plugin, which overlaps our tier rules, and the
  voice plugin, which needs OpenAI and duplicates our web phone.

## Verification

* `bash scripts/uv-run.sh python -m pytest -q` ran 293 tests and all passed.
  This includes 4 new sync tests and the plugin's own tests. One plugin test
  now imports from the repository root instead of an installed wheel.
* API on :8030 and UI on :8531 (`map-api`, `map-ui` in `.claude/launch.json`):
  * We added three typed calls; the map listed all three with address
    candidates and tier labels.
  * Refresh fetched 7 live NWS/USGS events with no error.
  * A Census geocode placed an unconfirmed diamond in downtown LA.
  * `/reset` emptied the map.
* Not verified:
  * Alert polygons draw only after a per-event geometry load, which we did
    not exercise.
  * The plugin UI is in Chinese.
  * Address accuracy was not measured.
